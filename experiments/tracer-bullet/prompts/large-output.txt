EXPERIMENT: Q3 (hook tool_output truncation threshold).

Run inside the scratch-project Claude Code session. Drives a tool across the
size bands {1KB, 100KB, 1MB, 10MB} so the captured PostToolUse `tool_output`
reveals whether/where Claude Code truncates. emit.mjs seeds byte-offset markers
every 512 bytes, so the LAST marker present in the captured output pinpoints the
truncation offset.

PROMPT TO CLAUDE CODE (run each line as a separate Bash tool call):
---
Run these four commands, one at a time, using the Bash tool, and report the byte
count you observe for each:
  node experiments/tracer-bullet/emit.mjs 1KB
  node experiments/tracer-bullet/emit.mjs 100KB
  node experiments/tracer-bullet/emit.mjs 1MB
  node experiments/tracer-bullet/emit.mjs 10MB
---

WHAT TO OBSERVE / CAPTURE AFTER THE RUN:
- For each band, the byte length of the captured PostToolUse `tool_output` vs the
  emitted length. Equal => no truncation at that band. Shorter => truncated;
  read the last `<<@NNNNNNNNN>>` marker for the exact cutoff offset.
- Whether truncation is measured in bytes or characters (all output is ASCII, so
  they coincide here — note it for the finer Phase-3 sweep if needed).
- Whether the hook payload carries any explicit truncation flag/field.

CAPTURE:
  node experiments/tracer-bullet/capture.mjs --exp large-output \
    --data-dir "$AGENT_LENS_DIR" --transcripts "<parent_transcript_path>"
