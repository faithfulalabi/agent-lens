Spawn TWO sub-agents, one after the other. Use the sub-agent spawning tool (it
appears in hook payloads as tool_name "Agent"). Do NOT do any of this work
yourself in the parent context — every command MUST run inside a spawned
sub-agent, because the whole point is observing whether the hooks fire inside

SUB-AGENT 1 — tool-heavy, and it must itself spawn a nested sub-agent.
Use the general-purpose agent type: it is the one with the spawning tool
available. (Narrow types like Explore cannot spawn, which is exactly what caps
a capture at spawnDepth 1.) Instruct it to:
  1. Run `echo "subagent-marker-one"` with the Bash tool.
  2. Run `node experiments/tracer-bullet/emit.mjs 1KB` with the Bash tool.
  3. Run `echo "subagent-marker-three"` with the Bash tool.
  4. Then spawn a NESTED sub-agent of its own that runs exactly one command,
     `echo "nested-marker"`, and reports what it saw.
  5. Report the total byte count it observed.

SUB-AGENT 2 — must FAIL with a non-zero exit code.
Instruct it to run exactly this with the Bash tool:
    node -e 'console.error("subagent-intentional-failure"); process.exit(3)'
and then report the exit code it saw. The non-zero exit IS the payload of this
half of the experiment — do not let it "recover", retry, or substitute a
command that succeeds. A clean run here is a failed capture.

Finally, in the parent context, state in one sentence what each sub-agent did.
